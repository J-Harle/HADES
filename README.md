# HADES
High-throughput Analysis for the Design of Energetic Systems

## Installation
Clone the HADES repo: `git clone https://github.com/J-Harle/HADES`

## Create HADES Environment
Create the HADES environment: `conda env create -f hades.yml`

## Command Line Interface (CLI)
Options:

--input / -i (Input path file) - use if a set of molecules are previously generated, otherwise molecules will need to  be generated         \n
--output / - o (Output path file) - specifies the name of the output file, defaults to "hades_out.csv"                                      \n
--generate / -g (Generate new molecules) - generate new molecules                                                                           \n
--optimise-generated / -opt (optimise molecules) - optimise all of the molecules generated by -g or provided by -i                          \n
--vibration / -v (frequency calculation) - run a frequency calculation on the optimised structures                                          \n
--impact-sensitivity / -s (impact sensitivity prediction) - predict the impact sensitivity of the generated molecules                       \n
--oxygen-balance / -ob (oxygen balance calculation) - calculate the oxygen balance of the -g or -i molecules                                \n
--enthalpy-of-formation / -eof (predict enthalpy of formation) - predict the enthalpy of formation for the -g or -i molecules               \n
--generic-properties / -gprop (predict generic properties) - calculate large number of properties available in rdkit                        \n

Example usage: 
`python hades.py -g -opt -v -s`
This will generate and optimise a set of molecules, then perform a frequency calculation and subsequently predict the impact sensitivity of the molecules
