# HADES
High-throughput Analysis for the Design of Energetic Systems

## Installation
Clone the HADES repo: `git clone https://github.com/J-Harle/HADES`

## Create HADES Environment
Create the HADES environment: `conda env create -f hades.yml`

## Command Line Interface (CLI)

Options:

- `--input` / `-i` (Input path file) – Use if a set of molecules are previously generated; otherwise molecules will need to be generated. (To use your own input files, provide a csv file with headers "CID" (where CID is the molecule ID), and "SMILES")<br>
- `--output` / `-o` (Output path file) – Specifies the name of the output file. Defaults to `hades_out.csv`.<br>
- `--generate` / `-g` – Generate new molecules.<br>
- `--optimise-generated` / `-opt` – Optimise all molecules generated by `-g` or provided by `-i`.<br>
- `--vibration` / `-v` – Run a frequency calculation on the optimised structures.<br>
- `--impact-sensitivity` / `-s` – Predict the impact sensitivity of the generated molecules.<br>
- `--oxygen-balance` / `-ob` – Calculate the oxygen balance of the `-g` or `-i` molecules.<br>
- `--enthalpy-of-formation` / `-eof` – Predict the enthalpy of formation for the `-g` or `-i` molecules.<br>
- `--generic-properties` / `-gprop` – Calculate a large number of properties available in RDKit.

Example usage: 
`python hades.py -g -opt -v -s` <br>
This will generate and optimise a set of molecules, then perform a frequency calculation and subsequently predict the impact sensitivity of the molecules
